# 我的 Git 学习笔记

课堂实验里我练习了 git init、add、commit 和 restore。印象最深的是 git status：每做一步都看一眼它，就知道现在哪些文件改了、哪些进了暂存区，心里有底。git log --oneline 能看到每次提交的记录，像游戏的存档列表一样。

## 第一次 Git 实验总结

1. `git add` 的作用是：把工作区里改过的文件放进暂存区，相当于挑出"这次要提交的内容"。没有 add 过的修改不会被提交进去。

2. `git commit` 的作用是：把暂存区里的内容打包成一个本地提交（存档），并附上一句提交说明。之后随时可以用 git log 查看，出问题也能回到以前的版本。

3. 本次实验中 `git restore notes.md` 的作用是：把 notes.md 里还没有提交的修改丢弃，让文件恢复成最近一次提交时的样子。实验里我往末尾追加了一句练习文字，restore 之后这句话就没了，笔记回到了干净状态。

4. `commit` 与 `push` 的区别是：commit 只把提交保存在自己的电脑上，别人看不到；push 是把本地的提交上传到远程仓库，组员和组长才能真正拿到你的代码。简单说 commit 是本地存档，push 是同步到云端给大家。
